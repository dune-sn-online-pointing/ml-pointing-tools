# Electron Direction scripts

Quick reference (high-level):

- `condor_wrapper_3plane_simple.sh`: HTCondor wrapper for basic 3-plane ED training.
- `wrapper_ed_enhanced.sh`: wrapper for enhanced ED training setups.
- `wrapper_ed_v52_hyperopt.sh`: wrapper for the v52 hyperopt workflow.
- `wrapper_v55.sh`: wrapper for v55-style workflows.

For full training instructions, see [docs/Training.md](../../docs/Training.md).
