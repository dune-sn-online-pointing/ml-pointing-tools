# Channel Tagging scripts

Quick reference (high-level):

- `train_channel_tagging.sh`: convenience wrapper for local CT training.
- `run_channel_tagging.sh`: run/evaluate CT models (depends on the JSON passed).
- `run_all_ct_analyses.sh`: batch-run CT analysis steps on an output directory.
- `wrapper_ct_simple.sh`: HTCondor wrapper used by submit files under `channel_tagging/condor/`.

For full training instructions, see [docs/Training.md](../../docs/Training.md).
